# 资源来源

- `assets.csv`：七件项目原创程序化几何及其源文件。未使用 Minecraft 资产。
- `fonts/`：Noto Serif SC 与 Noto Sans SC，SIL Open Font License 1.1。通过已锁版本的 Fontsource 包自托管。
- `assets/plates/*.png`：由本会话内置 image_gen 生成的原创入口概念图，基于用户批准的 A/B/C 方案；PNG 内嵌提示词。
- `public/assets/plates/*.webp`：上述图的 WebP 转码，邻接 `.webp.json` 保留生成提示词和工具来源，不作为实际游戏截图宣传。
- GLB、界面、世界几何由本项目代码生成；依赖许可证见各 npm 包。未采集第三方皮肤、贴图、音效或文学原文。

项目名称和公开叙事内容的权利状态仍待确认。本清单说明来源，不作法律结论。

音频：`src/game/audio.ts` 以原创振荡器和固定种子噪声生成常态风、异常风、脚步、仪器、钟声、设施、结算共七类反馈；没有使用外部录音。
