## 复核命令

```powershell
npm run check:assets
npm run check:handoff
```

`check:assets` 检查21件生产GLB的来源、文件名大小写、尺寸字段、实际面数／材质／纹理预算和交互点。`check:handoff` 从当前共享布局核对观象台可编辑源（只读），重新比对原生导出，重算整套预算，再比对六名人物的120条动画曲线及156种姿态，最后核对11个资产族覆盖、运行时加载清单、碰撞引用与许可登记。CI已加入这条命令，但远端CI尚未运行。
