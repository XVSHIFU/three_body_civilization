# 第二批可编辑仪器源

- thermometer：温度仪，0.65 × 2.05 × 0.55 米，独立 pointer 节点，120 三角形。
- archive_desk：档案台，2 × 1.21 × 1.1 米，石板与刻痕独立命名，120 三角形。

每件配有 `.design.json`，注明操作点、候选碰撞体、预算、作者、单位和未验收内容。它们是源文件阶段的设计交接，不在生产清单中；需先在 Blockbench 原生导出，核对模型、尺寸、颜色，再接入运行时与交互回归。当前正式场景仍使用原有几何。

重现命令：`npx tsx tools/generate-instrument-sources.ts`。发现源文件编辑时拒绝覆盖。不要通过删除手工编辑来绕过保护。

原生导出进展：已通过真实 Blockbench 界面导出两件 GLB，保存于 `reports/blockbench/*-native.glb`。`npx tsx tools/check-instrument-exports.ts` 的逐节点尺寸与UV取色核对通过，报告为 `*-source-roundtrip.json`。尚未替换正式场景；浏览器运行时材质、碰撞交互与远近识别仍待验收。

生产接入进展：两件现已注册正式清单与碰撞描述，并替换场景原位几何。温度仪指针读取当前气候温度；自动化加载、接近点贴地和最近遮挡交互射线测试通过。现场浏览器效果与真实键鼠验收仍待完成。上文“源文件阶段／未替换”描述为历史阶段，以此进展为准。
